# University Management System (UMS) - Agile Increment

This repository contains the C++ source code implementation for the **University Management System (UMS)** assignment, built following Agile, Scrum, and Extreme Programming (XP) methodologies.

## Assigned Features
1. **Course Registration (UMS-1):** Course lookup, selection, and capacity validation.
2. **Faculty Management (UMS-2):** Faculty directory and course assignment management.
3. **Student Academic Profile (UMS-3):** Academic records, enrollment summary, and profile details.

## XP Practices Applied
* **Pair Programming:** Collaborative development driver/navigator logs.
* **Test-Driven Development (TDD):** Red-Green-Refactor development cycle for core validation rules.
* **Code Refactoring:** Decoupling monolithic logic into modular functions.
* **Continuous Integration:** Structured feature branching and commit tracking.
